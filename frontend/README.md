# BrandPilot — Frontend

Angular UI for the BrandPilot social media management platform.

## Tech Stack

- Angular 19
- Angular CLI
- Karma (unit tests)
- Chart.js (dashboard analytics)

## Commands

| Command | Description |
|---|---|
| `ng serve` | Start dev server at `localhost:4200` |
| `ng test` | Run Karma unit tests |
| `ng build` | Build for production |
